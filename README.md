# 🏙️ Portfólio de Pedro (@mpdrao) // Torre dos Titãs

Portfólio pessoal e catálogo de projetos de software desenvolvido com estética nostálgica e melancólica inspirada no universo clássico da série animada **Jovens Titãs (Teen Titans - 2003)**.

🌐 **Acesse online:** [https://mpdrao.github.io](https://mpdrao.github.io) ou [https://mpdrao.github.io/portfolio](https://mpdrao.github.io/portfolio)

---

## 🌧️ Conceito Visual & Estética

- **Estilo Gráfico:** Inspirado na direção de arte clássica de Glen Murakami para Jovens Titãs (2003) — cortes angulares nos cartões (chanfrados), sombras com alto contraste de histórias em quadrinhos, estética cyberpunk sombria de Jump City.
- **Clima Melancólico:** Chuva sutil contínua renderizada via Canvas 2D, paleta de cores noturna (azul-noite, ardósia, violeta da Ravena e dourado/ciano dos comunicadores dos Titãs).
- **Gerador de Áudio Procedural:** Gerador sintetizado de chuva e ruído via Web Audio API nativa (sem necessidade de arquivos de áudio externos, acionável pelo botão "Chuva").
- **Terminal Interativo:** Console estilo mainframe da Torre dos Titãs que responde a comandos como `help`, `projects`, `skills`, `azarath`, `titans`, entre outros.
- **Comunicador dos Titãs:** Widget interativo que replica o clássico comunicador com a insígnia amarela em T.
